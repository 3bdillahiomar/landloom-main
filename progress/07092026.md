# Progress — 07 September 2026

Somalia Municipality Risk Dashboard — work completed this session.

## 1. Explored the dashboard & scoped Belet Weyne (Beledweyne)

- Reviewed the full stack: Django + GeoDjango + PostGIS + GeoServer + Leaflet,
  built for World Bank / GFDRR under SURP II (Nagaad Project).
- Recommended decision layers for Belet Weyne — riverine flooding from the
  Shabelle is the dominant hazard; displacement, conflict access, and rural
  drought are secondary.

## 2. Built a "flood-exposure" analysis feature

- **Data model**: added a `flood_exposed` boolean flag to `SURPII_Building` /
  `SURPII_Road` / `IDP` (migrations `0023`, `0024`) and a new
  `MunicipalityExposureSummary` table.
- **Batch computation** — `manager/exposure.py` + `compute_exposure` management
  command: one PostGIS pass over ~1M buildings using a subdivided flood polygon,
  ~42 s for all cities. Pivoted here from an on-request live-query design after
  profiling showed it was unworkable (44 s per query, 47k features).
- **API**: `GET /api/exposure/?municipality=&layer=` (GeoJSON or CSV) and
  `GET /api/exposure/summary/` (KPI JSON); custom CSV renderer; `?download=1`
  filenames like `BeletWeyne_Flood-exposed_roads.csv`.
- **Map + UI**: flood-exposed Buildings (GeoServer WMS, CQL-filtered), Roads and
  IDP Sites (GeoJSON) as toggleable overlays; a "Flood-exposed in <city>" KPI
  card with GeoJSON/CSV download links.
- **GeoServer**: ran a one-time catalog reload so the new `flood_exposed` column
  is visible to the CQL filter.
- **Belet Weyne result**: 47,008 exposed buildings, 434 km roads,
  133 IDP sites / 97,813 individuals, 515 conflict events (275 in the last
  3 years). Only SURP II city with significant flood exposure.

## 3. Polished the flood-exposure layers

- Layers start **off**; the user enables them from the control.
- Styled roads/buildings to match the base layers; IDP sites use orange
  (`#e6b031`).
- Layer control turned into **grouped accordion cards** (vendored
  `leaflet-groupedlayercontrol`): a "Map layers" group and a per-city
  "<city> — hazard-exposed" group whose title **renames with the municipality
  dropdown**.
- Added an `app.js?v=` cache-buster to prevent stale-JS confusion.

## 4. Reorganised the home page

- **Moved to the Municipalities page**: the Insurgent Event Records chart, the
  IDP Individuals by Municipality chart, and the Municipality IDP Settlement
  Inventory table — with the two charts now **side by side**.
- **Redesigned the four filters** into one accordion panel, built as progressive

  - collapsible sections with option counts and `+` / `−` icons
  - pale-green active-selection **chips** with `×` to clear each
  - a **search box** for municipality / district / region
  - custom single-select checkbox-style options
  - full keyboard support + ARIA, 44px touch targets
- **District (91)** and **Region (18)** show the **top 5 + "Show N more"**;
  search reveals all matches.
- Wrapped the relocated `#idpTable` in `.table-responsive` so it scrolls instead
  of overflowing on mobile.
