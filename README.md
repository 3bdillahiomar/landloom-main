# LandLoom

LandLoom is a web-based Land Information System (LIS) built with Django, GeoDjango, PostGIS, Django REST Framework, and Leaflet. It provides an interactive GIS interface for visualizing and managing land parcels, buildings, roads, and landmarks in Somalia.

## Features

- Interactive Leaflet web map
- Multiple basemaps
- Fullscreen control
- Layer search
- User geolocation
- Scale bar
- Land parcel visualization
- Buildings, roads, and landmarks
- Django REST API
- GeoJSON support

## Technology Stack

- Python
- Django
- GeoDjango
- PostGIS
- Django REST Framework
- Leaflet.js
- JavaScript
- HTML
- CSS

## Installation

```bash
git clone https://github.com/3bdillahiomar/landloom.git
cd landloom

python -m venv venv
source venv/bin/activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
